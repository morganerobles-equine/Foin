# Trois bottes · MS MESB

Application de séance pour le CM 4 « Même prairie, trois bottes » (nutrition équine, MS MESB, UniLaSalle Rouen).

- `index.html` : la page (étudiants, espace enseignante, écran projeté). Hébergée par GitHub Pages.
- `firestore.rules` : règles de sécurité à coller dans la console Firebase (Firestore → Règles).

Configuration : renseigner `FIREBASE_CONFIG` et `TEACHER_EMAIL` en haut de `index.html`.
